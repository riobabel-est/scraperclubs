--- MÉTRICA QUE USA EL ENVÍO (api/enviar_lote.php) ---
Calcula $enviadosHoyReal desde comunicaciones_log:
  SELECT COUNT(*) FROM comunicaciones_log
  WHERE id_cuenta_smtp = {id} AND DATE(fecha) = DATE('now')
Bloquea si: $enviadosHoyReal >= limite_diario.
=> El envío usa la métrica REAL calculada desde comunicaciones_log (fecha de hoy),
   NO el contador acumulado cuentas_smtp.enviados_hoy.

--- MÉTRICA QUE MUESTRA LA UI (api/smtp.php get_accounts) ---
Recalcula enviados_hoy desde comunicaciones_log:
  SELECT COUNT(*) FROM comunicaciones_log
  WHERE id_cuenta_smtp = {id} AND DATE(fecha) = DATE('now')
    AND tipo_evento = 'envio_email'
Conserva el acumulado en enviados_hoy_acumulado.
=> La UI usa la misma fuente de verdad (comunicaciones_log, fecha de hoy).
